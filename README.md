# ruby/.github

Organization-wide default files for the repositories in the [ruby](https://github.com/ruby) organization.

- `profile/README.md` is the organization profile shown at <https://github.com/ruby>.
- `SECURITY.md` is the default security policy. GitHub shows it in the Security tab of every repository in the organization that does not have its own.

See the [GitHub documentation on default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for how this repository works.
